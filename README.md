# Zenith Jeanz — runway site

A single-page runway: models walk toward the viewer in an endless perspective loop.
Hovering a model freezes the runway, and tapping one opens its product view.
The browser Back button closes it.

Shoppers can buy a whole look or single pieces. The nav filters the runway, and
search, wishlist and cart all work. Checkout goes through Shopify once it's connected.
See `SHOPIFY_SETUP.md`.

Hosting: GitHub Pages serves the site at zenithjeanz.com, and Shopify runs on
shop.zenithjeanz.com. See `DOMAIN_SETUP.md`.

## Run

```sh
python3 build.py                 # regenerates index.html
python3 -m http.server 8000      # then open http://localhost:8000
```

## Files

| Path | What it is |
|---|---|
| `index.html` | The built site with CSS and JS inline. Generated, so don't edit by hand. |
| `template.html` | Page source that `build.py` fills in. |
| `build.py` | Finds the clips in `media/` (one model each, sorted by filename) and inlines the logo, nav and product data. It transcodes any clip a browser can't play inline to H.264 MP4. |
| `media/NN_*.mp4` | Runway clips: 640×1252 H.264 on a white background, one 30-frame stride each. |
| `media/anim/`, `media/poster/` | Generated by `build.py`: an animated WebP and a still frame per clip. The page switches a model to its animation when the browser won't play the video (e.g. iPhone Low Power Mode), so the models always walk. |
| `brand/products.json` | The looks and their pieces: name, type, price and Shopify handle, plus sizes and currency. Looks are matched to clips in filename order. |
| `brand/store.json` | Shopify connection settings. Left blank, the site runs in demo mode. See `SHOPIFY_SETUP.md`. |
| `brand/shopify-products.csv` | Generated by `build.py`. Import it in Shopify (**Products → Import**) to create every piece with its sizes. |
| `brand/logo.svg` | Stacked logo traced from `logo-original.jpg`. |
| `brand/logo-horizontal.svg` | Horizontal lockup used in the header. |
| `brand/garment-sheet.png` | The original garment and price sheet. |

## Adding or replacing a look

1. Put the clip in `media/`. The filename prefix sets its runway position, for example `10_sacloth-hoodie.mp4`.
2. Make sure the look at the same position in `brand/products.json` describes it. Give each new piece a unique `handle`.
3. Run `python3 build.py`.

Raw clips should be full-body shots of a model walking at a 3/4 angle toward the right
of the frame, with the camera tracking them. The current clips came from Kling 3.0
(9:16, 720×1280). Each one was trimmed to the part after the model settles into the
walk, cut out onto pure white (rembg `birefnet-general-lite`), steadied so the
model stays the same size and position, and looped over one full stride. Loop
points come from pose landmarks, so the same leg is forward at both ends. Every
loop is then retimed to the same 30-frame (1.25 s) stride with optical-flow
in-betweens, so all models walk at one pace and the seam has no jump.

On the page the clips use `mix-blend-mode: multiply`. The white drops out, so
models pass in front of each other without a visible frame.

If a clip is missing or fails to load, that model shows a solid `#DCE3EA` fill.
The fill moves, dims and opens the product view the same way a video does.
